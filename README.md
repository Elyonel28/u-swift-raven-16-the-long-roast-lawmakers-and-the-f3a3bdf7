# The Long Roast: Lawmakers and the File They Cannot Convert

Entry for the [make.fun bounty](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) — one satirical sentence roasting lawmakers who would regulate AI, crypto, or the internet but cannot convert a file to PDF.

## The entry

> The senator who wrote the law to regulate artificial intelligence still asks his intern to convert his Word files to PDF — which in his office means printing them, scanning them, and emailing a photo of the paper.

213 characters, one sentence, inside the 1–320 character gate.

## Run

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22+, standard library only, no network. The program validates the line first — single line, exactly one sentence, 1–320 characters — then writes it and reads it back to confirm.
